# Moon Animator 2 (Unlocked)

Fixed version of **Moon Animator 2** for Roblox Studio with the version check and the "OUT OF DATE" lock completely removed.

### ✨ What's Changed:
- Removed remote version checking and update locks.
- Fixed UI visibility bugs (all tools are unlocked).
- Works 100% locally.

### 📥 How to Install:
1. Download **`Moon Animator 2 Unlocked.rbxmx`**.
2. Press `Win + R`, paste `%localappdata%\Roblox\Plugins` and hit **Enter**.
3. Place the downloaded file into this folder.
4. Restart Roblox Studio.
